# ECON BRAND KIT v1.0

## 1. Brand Identity
- **Name**: ECON
- **Tagline**: Economic Operating Layer for Autonomous Entities
- **Positioning**: Nebius × Financial Infrastructure × Autonomous Agent Operating System
- **Tone & Personality**: Confident, Technical, Optimistic, Infrastructure-grade, Bold, Clean, Engineered, Playful but serious.
- **Avoid**: Crypto casino neon, Web3 purple gradients, floating 3D brains, glowing cyberpunk borders, generic AI SaaS tropes.

---

## 2. Color System (80 / 10 / 7 / 3 Rule)

| Token Name | Hex Code | Role & Usage | Target Proportion |
|---|---|---|---|
| **ECON WHITE** | `#F7F8F2` | Primary page canvas, airy backgrounds, clean space | **80%** |
| **ECON GRAY** | `#E7E9E3` | Structural cards, secondary modules, subtle dividers | Base support |
| **ECON BORDER** | `#D6D9CF` | Hairline borders, structural frames | Base support |
| **ECON INK** | `#062A3B` | High-contrast typography, deep statement blocks, navigation | **10%** |
| **ECON BLACK** | `#071013` | Deep technical contrast, Monad settlement terminal | Contrast support |
| **ECON LIME** | `#CFFF3D` | Primary action buttons, hero highlight sections, key badges | **7%** |
| **ECON GREEN** | `#8DBB46` | Secondary positive metrics, verification seals | Accent support |
| **ECON PINK** | `#FF8FA3` | Economic Garbage Collector, stranded value indicators | **3%** |

---

## 3. Typography System
- **Primary Font**: `Inter`, `-apple-system`, `system-ui`, modern neo-grotesk sans-serif.
- **Monospace Font**: `Fira Code`, `JetBrains Mono`, tabular-nums for financial metrics, wallet hashes, code snippets, and telemetry.

### Hierarchy
- **Hero Display**: `clamp(56px, 7vw, 112px)`, weight: `800`, line-height: `0.92`, letter-spacing: `-0.03em`.
- **Big Statement**: `clamp(32px, 4.5vw, 64px)`, weight: `700`, line-height: `1.05`, letter-spacing: `-0.02em`.
- **Editorial Number**: `clamp(40px, 5vw, 72px)`, weight: `800`, font-family: mono.
- **Section Heading**: `24px – 32px`, weight: `700`, letter-spacing: `-0.02em`.
- **Body Text**: `14px – 16px`, weight: `400 – 500`, line-height: `1.6`, color: `#062A3B`.
- **Caption / Meta**: `11px – 12px`, weight: `600`, letter-spacing: `0.06em`, uppercase.

---

## 4. Corner Geometry System
- **Small (`8px`)**: Input fields, badges, table cells, metric chips.
- **Medium (`16px`)**: Data panels, transaction modules, code preview boxes.
- **Large (`24px`)**: Hero content cards, editorial statement containers.
- **Extra Large (`32px`)**: Giant colored statement sections, landing feature blocks.
- **Pill (`999px`)**: Primary action buttons, navigation toggles, status pills.

---

## 5. Editorial Section Rhythm
1. **White Hero (`#F7F8F2`)**: Bold statement, abstract system visualization, action CTAs.
2. **Ink Statement (`#062A3B`)**: High-contrast thesis on autonomous agent economics.
3. **Lime Section (`#CFFF3D`)**: Highlighting the transaction, discovery, and escrow engine.
4. **Soft Gray Section (`#E7E9E3`)**: Programmable economic objects & policy guard.
5. **Pink-Accented Section (`#FF8FA3`)**: Signature **Economic Garbage Collector** showcase.
6. **Dark Grid Section (`#071013`)**: Monad EVM 10,000 TPS sub-cent settlement engine.
